# 📘 Android Dev Handbook

A public, structured Android development handbook built with **MkDocs Material**.

🌐 Website:
https://khodorkin-dmitrii.github.io/android-dev-handbook/

## 📌 About

Android Dev Handbook is a compact knowledge base for Android development.

It covers:

* Android fundamentals
* Kotlin
* Java
* Jetpack Compose
* Coroutines & Flow
* Architecture
* Testing
* Networking
* Performance
* Core engineering concepts

Main content language (for now): **Russian**.

## 🛠 Tech stack

* Markdown
* MkDocs
* MkDocs Material
* GitHub Actions
* GitHub Pages

## 💻 Local preview

Run these commands from the repository root:

```bash
mkdocs build
mkdocs serve
```

Then open the Short Audio Notes page:

1. EN: [http://127.0.0.1:8000/android-dev-handbook/en/audio-shorts/](http://127.0.0.1:8000/android-dev-handbook/en/audio-shorts/)
2. RU: [http://127.0.0.1:8000/android-dev-handbook/ru/audio-shorts/](http://127.0.0.1:8000/android-dev-handbook/ru/audio-shorts/)
