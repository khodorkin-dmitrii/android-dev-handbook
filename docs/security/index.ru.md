# Основы безопасности Android

Безопасность Android-приложения строится вокруг защиты пользовательских данных и сессий с учетом того, что клиент работает на устройстве вне контроля приложения. Эта обзорная статья задаст практические границы угроз и свяжет решения по защите трафика, локальному хранению и аутентификации, не уходя в общую кибербезопасность.
