# Certificate Pinning

Certificate pinning сужает набор серверных идентификаторов, которым приложение доверяет после стандартной проверки платформой. Этот механизм может снизить отдельные риски цепочки доверия, но добавляет требования к развертыванию, восстановлению, тестированию и ротации сертификатов, поэтому не должен быть обязательной настройкой для каждого Android-приложения.
