# Legacy

This section helps maintain Android code that still uses older libraries and patterns. It currently contains one article; other legacy topics live in their relevant domains rather than being repeated here.

## Where to start

- [RxJava](rxjava.md) - reactive types, scheduling, backpressure, subscription ownership, and gradual migration toward Coroutines and Flow.

For older dependency injection, see [Legacy DI](../di/legacy-di.md). For changing existing architecture safely, see [Legacy & Refactoring](../architecture/legacy-refactoring.md). [Coroutines & Flow](../coroutines-flow/index.md) covers the modern alternatives to Rx-based application code.
