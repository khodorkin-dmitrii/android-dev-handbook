# scrcpy: трансляция экрана Android

## Практическая инструкция

### Что это и когда полезно

`scrcpy` - бесплатный open-source инструмент для отображения экрана Android на компьютере и управления мышью и клавиатурой через USB или TCP/IP. Работает на Windows, macOS и Linux; root и ручная установка приложения на телефон не нужны.

Подходит для проверки UI на физическом устройстве, демонстраций, записи воспроизведения бага и работы с телефоном с компьютера. Основной сценарий этой инструкции - USB и Windows.

### Установка на Windows

Выполни в PowerShell или CMD:

```powershell
winget install --exact Genymobile.scrcpy
```

WinGet устанавливает ADB и необходимые зависимости вместе со scrcpy. После установки открой терминал заново и проверь:

```powershell
scrcpy --version
```

Альтернатива - Windows ZIP для архитектуры твоего компьютера из официальных [GitHub Releases](https://github.com/Genymobile/scrcpy/releases). Распакуй архив и открой терминал в полученном каталоге. В PowerShell замени `scrcpy` на `.\scrcpy.exe` в командах ниже, если инструмент отсутствует в `PATH`. Для ADB из архива при необходимости используй `.\adb.exe`.

Для других платформ смотри официальные инструкции: [macOS](https://github.com/Genymobile/scrcpy/blob/master/doc/macos.md) и [Linux](https://github.com/Genymobile/scrcpy/blob/master/doc/linux.md).

### Подготовка телефона

1. Включи **Developer options**, обычно несколькими нажатиями на **Build number**. Расположение зависит от производителя.
2. Включи **USB debugging**.
3. Подключи телефон USB-кабелем с передачей данных.
4. Разблокируй телефон и подтверди RSA-разрешение на отладку для этого компьютера.
5. Проверь подключение:

```powershell
adb devices
```

Ожидаемый статус устройства - `device`. Включать MTP/File transfer не обязательно.

### Запуск

Начни с запуска без звука:

```powershell
scrcpy --no-audio
```

Чтобы попробовать профиль с повышенным лимитом FPS:

```powershell
scrcpy --video-codec=h264 --max-fps=120 --max-size=1920 --video-bit-rate=16M --no-audio --print-fps
```

| Параметр | Значение |
|---|---|
| `--video-codec=h264` | Выбор H.264; этот кодек также используется по умолчанию. |
| `--max-fps=120` | Верхний предел, а не гарантия 120 FPS. |
| `--max-size=1920` | Ограничение размеров видео с сохранением пропорций; результат не обязательно 1920×1080. |
| `--video-bit-rate=16M` | Целевой видеобитрейт 16 Мбит/с. |
| `--no-audio` | Отключение передачи звука. |
| `--print-fps` | Вывод частоты захвата кадров в терминал. |

Частота кадров переменная: на статичном экране она может быть низкой, поскольку новые кадры создаются при изменении содержимого экрана. Этот показатель не заменяет профилирование кадров приложения.

Экран появляется в отдельном окне. Можно управлять мышью и клавиатурой или продолжать пользоваться телефоном напрямую. Для завершения закрой окно или нажми `Ctrl+C` в терминале.

### Ещё несколько полезных команд

```powershell
# Менее требовательный профиль
scrcpy --max-fps=60 --max-size=1280 --video-bit-rate=8M --no-audio

# Запись экрана без звука
scrcpy --no-audio --record=demo.mp4

# Выбор устройства по серийному номеру из adb devices
scrcpy --serial=SERIAL --no-audio

# Справка
scrcpy --help
```

Замени `SERIAL` серийным номером устройства. Относительный путь записи, например `demo.mp4`, отсчитывается от текущего каталога терминала.

Как сделать из записи короткий GIF, описано в статье [FFmpeg для демо приложений](ffmpeg.md).

### Типичные проблемы

* **Команда не найдена:** открой новый терминал, проверь `PATH` или запусти `.\scrcpy.exe` из распакованного каталога.
* **`unauthorized`:** разблокируй телефон и подтверди разрешение на отладку.
* **Устройство отсутствует:** проверь USB debugging, кабель передачи данных и USB-порт; при необходимости установи драйвер производителя для Windows.
* **Несколько устройств или эмуляторов:** выбери нужное через `--serial`.
* **Низкий FPS или заметная задержка:** снизь разрешение и лимит FPS, попробуй менее требовательный профиль выше. Повышение битрейта само по себе не повышает FPS.
* **Экран виден, но ввод не работает на некоторых Xiaomi:** проверь отдельную настройку **USB debugging (Security Settings)**. Согласно официальной документации после её включения требуется перезагрузка.
