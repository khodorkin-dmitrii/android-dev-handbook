# FFmpeg для демо приложений

FFmpeg помогает превратить запись экрана Android в короткий зацикленный GIF для README или документации. Как записать экран физического устройства в MP4, описано в статье [scrcpy: трансляция экрана Android](scrcpy.md).

## Подготовка GIF

### Установка на Windows

Установи FFmpeg через WinGet в PowerShell или CMD.

```powershell
winget install --exact --id Gyan.FFmpeg
```

Открой новый терминал и проверь установку.

```powershell
ffmpeg -version
```

На официальной [странице загрузок FFmpeg](https://ffmpeg.org/download.html) есть сборки и пакеты для Windows, macOS и Linux.

### Преобразование MP4 в GIF

Открой PowerShell или CMD в каталоге с файлом `audioDemo.mp4`.

1. Создай палитру по кадрам, которые войдут в GIF.

    ```powershell
    ffmpeg -i audioDemo.mp4 -vf "fps=16,scale=500:-1:flags=lanczos,palettegen=max_colors=48" -frames:v 1 -update 1 palette.png
    ```

2. Примени палитру и сохрани GIF.

    ```powershell
    ffmpeg -i audioDemo.mp4 -i palette.png -filter_complex "[0:v]fps=16,scale=500:-1:flags=lanczos[v];[v][1:v]paletteuse=dither=bayer" audioDemo.gif
    ```

| Параметр | Что делает |
|---|---|
| `fps=16` | Задаёт частоту 16 кадров в секунду. |
| `scale=500:-1` | Задаёт ширину 500 px и рассчитывает высоту с сохранением пропорций. |
| `flags=lanczos` | Выбирает алгоритм масштабирования Lanczos. |
| `max_colors=48` | Ограничивает число используемых цветов в палитре. |
| `dither=bayer` | Применяет упорядоченный дизеринг для передачи промежуточных оттенков. На градиентах может быть заметен узор. |

**FPS и масштаб должны совпадать в обеих командах.** Палитра строится по кадрам, которые войдут в GIF. Если исходное видео изменилось, создай палитру заново.

### Подбор размера и качества

Для короткого демо интерфейса начни с 16 FPS, ширины 500 px и 48 цветов.

- Если мелкий текст плохо читается, попробуй увеличить ширину.
- Если градиенты выглядят грубо, попробуй `max_colors=64` или `max_colors=96`, создай палитру заново и сравни результаты.
- Если файл GIF слишком большой, сначала сократи клип, затем попробуй уменьшить ширину или FPS.

Перед публикацией сравни размеры файлов GIF и MP4 и проверь, какие форматы принимает площадка. Если в демо важен звук, используй MP4.

Другие параметры описаны в [документации фильтров FFmpeg](https://ffmpeg.org/ffmpeg-filters.html).
