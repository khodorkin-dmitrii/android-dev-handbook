# Jetpack Compose

This section covers Jetpack Compose for Android: declarative UI, layout, state, recomposition, side effects, navigation, performance, and UI testing.

For a practical learning path, start with Compose basics and layouts, then study state and side effects together. Continue with navigation, and use the performance and testing articles when building production screens.

## UI foundations

- [Compose Basics](basics.md) - composable functions, declarative UI, modifiers, previews, and interoperability with the View system.
- [Compose Layouts & Containers](layouts.md) - `Row`, `Column`, `Box`, lazy containers, adaptive layouts, `ConstraintLayout`, and custom `Layout`.

## State and behavior

- [State & Recomposition](state-recomposition.md) - state ownership, hoisting, stability, derived state, and recomposition control.
- [Side Effects](side-effects.md) - effect APIs, coroutine lifecycles, updated values, and observing Compose state safely.
- [Compose Navigation](navigation.md) - destinations, routes, arguments, back stack, nested graphs, and state restoration.

## Production quality

- [Compose Performance](performance.md) - measurement, lazy-list identity, stability, frequently changing state, and avoiding unnecessary work.
- [Compose Testing](testing.md) - semantics, stable selectors, synchronization, test rules, and deterministic UI tests.
