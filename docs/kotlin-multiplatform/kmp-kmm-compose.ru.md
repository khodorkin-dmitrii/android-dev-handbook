# KMP, KMM и Compose Multiplatform

В этой статье будут разобраны связи между Kotlin Multiplatform, прежним ориентированным на мобильную разработку названием Kotlin Multiplatform Mobile и Compose Multiplatform. Материал зафиксирует корректную терминологию и объяснит, почему использование KMP не обязательно означает общий UI.

> **Черновик:** Эта статья является структурированной заготовкой и будет расширена в следующей задаче.

## Темы для раскрытия

- Современная терминология KMP
- KMM как прежнее название мобильного направления
- Compose Multiplatform как UI-технология
- Использование KMP без общего UI
- Распространенные ошибки в терминологии
