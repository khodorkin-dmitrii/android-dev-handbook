# Архитектура и стратегии UI

В этой статье будут сопоставлены архитектурные подходы и стратегии переиспользования UI в продуктах на Kotlin Multiplatform. Материал охватит нативные, общие и гибридные решения с учетом границ навигации и lifecycle, требований продукта и возможностей команды.

> **Черновик:** Эта статья является структурированной заготовкой и будет расширена в следующей задаче.

## Темы для раскрытия

- Общие data- и domain-слои
- Платформенный нативный UI
- Общий UI на Compose Multiplatform
- Гибридные подходы
- Границы навигации и lifecycle
- Выбор стратегии с учетом продукта и команды
