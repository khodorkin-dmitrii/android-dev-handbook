# Структура проекта и Source Sets

В этой статье будет описана концептуальная структура Kotlin Multiplatform-проекта и организация кода по targets, compilations и source sets. Основное внимание будет уделено границам зависимостей и структуре Gradle без привязки к конкретным версиям и пошаговой настройке.

> **Черновик:** Эта статья является структурированной заготовкой и будет расширена в следующей задаче.

## Темы для раскрытия

- Targets и compilations
- `commonMain` и `commonTest`
- `androidMain` и `iosMain`
- Промежуточные и общие source sets
- Размещение зависимостей
- Концептуальная структура Gradle
