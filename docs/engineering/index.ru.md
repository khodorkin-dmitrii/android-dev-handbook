# Инженерные основы

Инженерные темы для Android-разработки: от сопровождаемого кода и поведения runtime до систем, объединяющих мобильный клиент и сервисы.

## Порядок изучения

Начните с качества кода и ревью, затем рассмотрите ООП, SOLID и паттерны через практические решения. Алгоритмы и память помогают оценивать производительность. Для распределённых функций начните с основ System Design, затем выбирайте тему по задаче; пример offline-first приложения объединяет эти идеи. Структура самого Android-приложения рассмотрена в разделе [Архитектура](../architecture/index.ru.md).
