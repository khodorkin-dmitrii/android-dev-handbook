# Engineering

Engineering concepts that support Android development, from maintainable code and runtime behavior to systems spanning mobile clients and services.

## Suggested path

Start with code quality and reviews, then revisit OOP, SOLID, and patterns through real design choices. Algorithms and memory help evaluate performance. For distributed features, begin with System Design Fundamentals and continue with the topic that matches your problem; the offline-first example connects the pieces. For Android-specific application structure, see [Architecture](../architecture/index.md).

- [Code Review](code-review.md) - focused changes and risk-based feedback.
- [OOP](oop.md) - encapsulation, contracts, and composition.
- [SOLID](solid.md) - principles applied without unnecessary abstractions.
