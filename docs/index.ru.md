# Android Dev Handbook

Android Dev Handbook - это структурированный справочник по Android-разработке: Kotlin, Java, Jetpack Compose, Coroutines & Flow, архитектура, тестирование, работа с сетью, хранение данных, производительность и базовые инженерные концепции.

Цель проекта - собрать практичные объяснения, короткие заметки, важные нюансы и примеры, которые помогают быстро освежить знания по Android-разработке.

## Разделы

* [Android](android/index.md) - Android SDK, компоненты приложения, lifecycle, View System, хранение данных, фоновая работа, производительность, поведение платформы и rendering.
* [AI](ai/overview.md) - on-device AI на Android, ML Kit, LiteRT, интеграция моделей, inference и выбор подходящего API.
* [Kotlin](kotlin/index.md) - основы Kotlin, Kotlin vs Java, классы и типы, коллекции, функции, generics и идиоматичный Kotlin.
* [KMP](kotlin-multiplatform/overview.md) - архитектура Kotlin Multiplatform, структура проекта, shared и platform-specific код, UI-стратегии и особенности внедрения.
* [Jetpack Compose](compose/index.md) - declarative UI, state, recomposition, side effects, производительность и тестирование Compose UI.
* [Coroutines & Flow](coroutines-flow/index.md) - coroutines, structured concurrency, cancellation, Flow operators, `StateFlow`, `SharedFlow` и lifecycle-aware collection.
* [Architecture](architecture/index.md) - современная Android-архитектура, Clean Architecture, MVVM, MVI, UI state, модульность и рефакторинг legacy-кода.
* [Java](java/index.md) - Java core, collections, exceptions, concurrency, JVM и особенности Android Runtime.
* [DI](di/index.md) - Dependency Injection, Hilt, Dagger, scopes, modules и dependency graph.
* [Networking](networking/index.md) - HTTP, REST, Retrofit, OkHttp, serialization, error handling, GraphQL, gRPC и Protocol Buffers.
* [Security](security/index.md) - основы безопасности Android, HTTPS и TLS, certificate pinning, secure storage, OAuth, PKCE и управление токенами.
* [Tools](tools/overview.md) - debugging, diagnostics, profiling, benchmarking, production monitoring и QA-friendly internal builds.
* [Testing](testing/index.md) - testing strategy, unit tests, `ViewModel` tests, Coroutines & Flow testing, Espresso и Compose UI tests.
* [Engineering](engineering/index.md) - базовые инженерные темы: OOP, SOLID, паттерны проектирования, алгоритмы, сложность, память и runtime-концепции.
* [Legacy](legacy/index.md) - старые, но всё ещё встречающиеся подходы и библиотеки Android/Java/Kotlin: RxJava, RxAndroid, legacy patterns и миграция на современный стек.
